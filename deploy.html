🚀 上线指南：让手机电脑都能访问

这个知识库是纯静态网页（无数据库、无后端），发布非常简单。本页给出三条路径：先在同一 Wi-Fi 下用手机验证效果，再选免费托管或服务器+域名正式对外。

① 局域网预览 零成本

电脑开一个本地服务，同一 Wi-Fi 的手机直接用"电脑IP:端口"访问。适合先验证手机上的效果。

② 免费静态托管 推荐

把整个文件夹传上去，免费获得一个网址，手机电脑直接打开。无需服务器、无需备案（托管在境外）。

③ 服务器 + 域名 完全自主

自己的云服务器放网站，域名解析到服务器 IP。国内服务器需要 ICP 备案，适合长期使用。

① 局域网预览：同一 Wi-Fi 下手机直接访问

在本站点根目录下打开命令行（在该文件夹地址栏输入 cmd 回车），运行：

python -m http.server 8000

然后查一下电脑的内网 IP（命令行输入 ipconfig，找"IPv4 地址"，形如 192.168.1.x），手机连同一个 Wi-Fi，浏览器打开：

http://192.168.1.x:8000
💡 注意：这只是"同一个 Wi-Fi 内"能访问，出门后打不开。但它能完整验证手机上的排版和交互，确认没问题再走路径②或③。若访问不了，多半是电脑防火墙拦了 8000 端口，临时放行即可。

② 免费静态托管（推荐，10 分钟搞定）

本网站是纯静态文件，天然适合静态托管。任选其一，把除 history 文件夹外的全部文件上传即可：

平台做法免费网址形式
GitHub Pages注册 GitHub → 新建仓库 → 上传文件 → Settings 里开启 Pages你的用户名.github.io/仓库名
Cloudflare Pages注册后直接拖拽上传整个文件夹，国内访问速度较好项目名.pages.dev
Netlify打开官网，把文件夹拖进上传区即完成发布项目名.netlify.app
Vercel注册后导入仓库或直接上传项目名.vercel.app
✅ 发布后把网址发给自己手机打开即可。这些平台的服务器在境外，不需要备案。以后想换成自己的域名，在平台里添加自定义域名并按提示做一条解析即可。

③ 自己的服务器 + 域名（完全自主）

步骤

步事项说明
1买云服务器轻量应用服务器即可（1核1G足够放静态站），选 Ubuntu/CentOS
2装 Nginx一行命令安装：apt install nginx 或 yum install nginx
3放网站文件把站点文件上传到 /var/www/html（或自定义目录并在 Nginx 配置里指向它）
4开放端口云控制台安全组放行 80（http）和 443（https）端口
5用 IP 访问浏览器打开 http://服务器公网IP 就能看到网站——这就是你说的"搜 IP 能看到网页"
6买域名并解析域名商处购买域名，添加 A 记录指向服务器公网 IP，几分钟后即可用域名访问
7上 HTTPS用 certbot 免费申请证书：certbot --nginx，网址变 https 且手机添加到主屏体验更好
⚠️ 备案提醒：服务器在中国境内且要绑域名对外提供服务，必须完成 ICP 备案（在云服务商后台提交，个人备案一般 1–2 周）。未备案的域名解析到国内服务器会被拦截。 只用 IP 访问、或服务器在境外，则不需要备案。个人学习站内容健康，正常备案即可通过。

❓ 域名访问和 IP 访问的区别

对比项IP 直接访问域名访问
是否需要购买不用，服务器自带公网 IP需购买域名（.com 约 60 元/年）
是否需要备案不用服务器在境内必须备案
记忆难度难记，且换服务器就变好记、稳定，适合长期使用
HTTPS 证书多数浏览器不支持给纯 IP 发证书可免费申请，安全性与主屏体验更好
💡 务实路线：先用 IP 或免费托管地址自己用着；确定长期用，再买域名 + 备案 + HTTPS，一步到位。

📱 手机添加到主屏幕（像 App 一样打开）

网站已配置好图标与全屏参数，添加后从主屏打开没有浏览器地址栏，就是一个"学习 App"。

iPhone（Safari）

打开网址 → 点底部"分享"按钮 → 选择"添加到主屏幕" → 确认。桌面会出现火焰图标。

安卓（Chrome 等）

打开网址 → 点右上角菜单（⋮）→ "添加到主屏幕"或"安装应用" → 确认。

💾 多设备使用与数据说明

学习数据（打卡、错题、日志等）保存在每台设备自己的浏览器里——这是纯本地方案的隐私优势，也意味着手机和电脑的数据默认不互通。
换设备/换浏览器时：在「进度追踪」页点"导出备份（JSON）"，到新设备的同一页面点"导入备份"即可完整迁移。建议每月导出一次，备份文件顺手存到网盘。
